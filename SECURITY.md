# Security policy

## Supported version

Security fixes are provided for the latest published release. Version 0.2.0 is
an alpha release intended for controlled evaluation on Moodle 5.2.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the
repository's GitHub private vulnerability reporting feature. Include the
affected version, deployment model, reproduction steps, and potential impact.

Do not include live AWS credentials, signed requests, Moodle backup archives,
personal data, or production configuration in a report.

The normative trust boundaries and required controls are documented in
[`docs/security-model.md`](docs/security-model.md).
