# Secure S3 Storage 0.2.2

This alpha release candidate prepares the plugin for Moodle Marketplace review.
It adds Moodle Plugin CI coverage for Moodle 5.2 with MariaDB and PostgreSQL at
the PHP 8.2 and 8.4 compatibility endpoints, while the existing ZIP release
gate continues to install and restore a real course backup in an empty Moodle
environment.

The Composer dependency platform now targets the documented minimum PHP 8.2.
Release ZIP files include the pinned AWS SDK and reconstruction instructions
inside the bundled third-party runtime directory. Marketplace documentation now
states the external-service, personal-data, AWS account, and operating-cost
boundaries explicitly.

This remains an alpha release for controlled evaluation. Database,
`moodledata`, configuration, and locally installed code still require separate
backup and recovery procedures.
