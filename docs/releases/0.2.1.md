# Secure S3 Storage 0.2.1

This alpha release fixes transfer failure reporting and is the first version
validated end to end against Amazon S3 from an EC2-hosted Moodle 5.2 deployment.

The production-equivalent validation used the EC2 instance role through the
AWS SDK default credential provider chain; no static AWS access keys were
stored in Moodle or Docker environment files. A Moodle-generated course backup
was uploaded and read back for verification, downloaded from S3, checked
against the SHA-256 digest encoded in its object key, restored as a separate
course, and verified using a marker in the restored Page activity.

The release ZIP bundles its pinned AWS SDK dependencies. CI separately installs
that ZIP into an empty Moodle environment, transfers a real course backup to
MinIO, downloads it, verifies its digest, and restores the course.

This remains an alpha release for controlled evaluation. It does not provide
complete site disaster recovery: the database, `moodledata`, configuration,
and locally installed code require separate backup and recovery procedures.
