# Secure S3 Storage 0.2.0

This is the first public alpha release for Moodle 5.2.

It transfers completed Moodle course backup archives to Amazon S3, verifies the
remote object through a streamed SHA-256 read-back, records idempotent transfer
state, and preserves the local archive. AWS credentials are obtained from the
AWS SDK default credential provider chain and are never stored in Moodle
settings.

The release ZIP bundles its pinned AWS SDK dependencies. CI installs that ZIP
into an empty Moodle environment, transfers a real course backup to MinIO,
downloads it, verifies its digest, and restores the course.

This release does not provide complete site disaster recovery. Database,
`moodledata`, configuration, and locally installed code require separate backup
and recovery procedures.
