# Secure S3 Storage 0.2.3

This documentation-focused alpha release candidate incorporates the reviewed
installation and operations guidance for Moodle Marketplace submission. It
explains the required Moodle automated course-backup schedule, shared backup
directory, Cron processing, S3 transfer, local retention, and restore checks.

A concise security-first roadmap now records the planned order for database
backup, local content backup, native S3 primary-content storage without an
external plugin dependency, and independent protection of that primary S3
content. Detailed architecture documentation separates plugin policy and
transfer responsibilities from privileged deployment operations.

Runtime behavior is unchanged from version 0.2.2. This release transfers only
stable Moodle-generated `.mbz` course backup archives. Database backup, content
backup, and primary S3 content storage are not implemented or enabled. The
plugin remains alpha and transfers remain disabled by default.
